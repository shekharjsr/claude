# Contributing to PSS 2.0

Thanks for your interest in PSS 2.0.

The project is currently in internal deployment at Volkswagen Group and is not yet open for external contributions. We're preparing to open-source the core components — the multi-cloud telemetry ingestion layer and the carbon intensity grid integration — ahead of our planned Q1 2027 release.

---

## How to stay involved until then

**Watch this repo.** We'll post updates here as the open-source release approaches, including what will be released, how the contribution process will work, and where help will be most useful.

**Open a discussion.** If you're building something in the same space — multi-cloud emission tracking, carbon-aware scheduling, sustainability reporting — feel free to open a GitHub Discussion. We're interested in hearing what problems other teams are running into, and it helps us shape what the open-source release actually covers.

**Report issues with public documentation.** If something in the README or ROADMAP is unclear or inaccurate, open an issue. We'll treat that as a valid contribution even before the code is public.

---

## What we're looking for when contributions open

When the project does open up, the areas where outside help will matter most are:

- GCP and other cloud provider support beyond AWS and Azure
- Regional carbon intensity data sources (we're aware coverage varies significantly outside Europe and North America)
- Terraform and infrastructure-as-code packaging
- Documentation and example configurations for self-hosted deployments

If any of those match what you work on, it's worth keeping an eye on the Q1 2027 release.

---

## Code of conduct

PSS 2.0 will adopt the [Contributor Covenant](https://www.contributor-covenant.org/) when contributions open. The short version: be direct, be respectful, stay focused on the work.

---

For anything else, open a GitHub Discussion or reach out via the contact details on the maintainer's profile.
